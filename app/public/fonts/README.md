# Brand fonts

The UI uses Telegraf (text) and Agrandir (display), both by Pangram Pangram.
Their free download is for personal use only, so the files are not in this
repo. With a desktop/app license, drop the files here using these names
(`.woff2` preferred, `.otf` also works):

- `PPTelegraf-Regular`, `PPTelegraf-UltraBold`
- `PPAgrandir-Regular`, `PPAgrandir-TextBold`, `PPAgrandir-GrandHeavy`

Without them the app falls back to Roboto Flex.
